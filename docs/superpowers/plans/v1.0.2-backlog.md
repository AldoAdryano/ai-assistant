## Hapus Seluruh Tugas (DELETE_ALL_TASK)
- **Issue:** User mengirim "hapus seluruh tugas" tetapi bot hanya membalas menu V1.
- **Expected Behavior:**
  1. Sistem mengenali intent `DELETE_ALL_TASK`.
  2. Sistem tidak langsung menghapus (membutuhkan konfirmasi).
  3. Sistem meminta konfirmasi (mis. "Apakah Anda yakin ingin menghapus semua tugas?").
  4. Setelah user menjawab YA, semua task di Notion di-archive (status diubah menjadi selesai atau dihapus permanen, sesuai standar Notion API).
  5. Setelah selesai, bot memberikan jumlah task yang berhasil dihapus.
